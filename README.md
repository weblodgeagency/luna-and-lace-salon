# Luna & Lace Salon — Hair Salon, Austin TX

A single-page website for a boutique hair salon in Austin, Texas — services with prices, stylist profiles, client reviews, opening hours, and appointment booking.

**Live site:** https://weblodgeagency.github.io/luna-and-lace-salon/

Built with plain HTML and CSS (no framework): sticky navigation, hero, priced services, stylists, reviews, hours and location.

Website designed & built by [Weblodge Agency](https://weblodge.agency).
